# Frozen architecture handoff

`architecture::{export, encode, decode}` supports exactly `specguard.architecture-handoff/v1alpha1`. Export consumes an actual frozen SourceSnapshot, a ValidatedBaseline from the approval boundary, and a nonempty requirement scope covered by that baseline. Every scoped requirement must have an explicit valid ADR reference. Missing, partial, malformed, conflicting or dangling trace coverage fails export. It never infers Cargo packages, rules or architectural compliance from names.

The artifact contains the immutable full baseline and its digest, repository, exact candidate/base/object-format binding, frozen source digest/scope, full source snapshot, trace artifact and derived requirement/ADR/reference locations. Decode has a 1 MiB raw JSON cap, strict fields/version, bounded baseline graph and existing pre-parser admission. It recomputes the snapshot digest, re-parses actual embedded source bytes and compares all trace nodes/findings/references. SourceRef itself remains path+line; content integrity comes from its embedded snapshot. This validates frozen bytes and OID syntax, not proof those bytes form a clean Git commit tree.

Consumers must provide ExpectedHandoff pins from their own protected context: raw-byte artifact SHA-256, repository, candidate/base/object format, baseline digest, source digest, scope and authentication profile. Reading those expectations from the same untrusted artifact provides no trust. Object existence and current candidate selection remain host responsibilities. Baseline graph integrity is checked, but neither decode nor self-consistent digests authenticate an approval issuer or revalidate live revocation.

Only `fixture-only` is serializable. Production approval authentication remains unavailable. The actual exporter/parser/reader code is real; the approval port and demonstration repository are explicit fixtures. This local profile must remain advisory and cannot authorize a gate. ArchGuard owns its reader and any protected mapping from explicit requirement/ADR IDs to existing architecture policy. SpecGuard supplies references and immutable baseline/source context, never ArchGuard policy.

Generate evidence with `cargo run --locked --example generate_architecture_handoff -- <fresh-directory>`. The generator uses real temporary Git and real Markdown files, reuses the established baseline fixture, and records its implementation commit, actual candidate commit object, baseline digest and raw-byte artifact digest. The baseline's original TestGuard obligation golden remains unchanged. Actual cross-repository consumer commands/results are recorded separately in the implementation ledger, not inferred from SpecGuard unit tests.
